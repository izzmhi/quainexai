      Phone control

      Quainex polls Telegram outwards, so nothing on this machine is exposed to the internet — no port forwarded, no certificate needed. It needs two things: a bot token, and the list of accounts allowed to use it. A bot with an empty allowlist would take orders from anyone who found it, so Quainex refuses to poll without one.

      Allowed accounts Numeric Telegram user ids, comma separated. Message @userinfobot to get yours. Saving replaces the whole list, so removing an id revokes it immediately.
